# ApexTX brand assets

The ApexTX mark and wordmark were created for this project. The approved source
is `apextx-logo-source.jpg`; `apextx-logo.png` and the firmware assets are
generated by `tools/nb4-brand-assets.py`.

The source image and its derived artwork are distributed with ApexTX under the
same GPL-2.0-only terms as the project. ApexTX is independent from FlySky
and EdgeTX. Their names and marks remain the property of their respective
owners.
