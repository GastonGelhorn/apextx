NOBLE NB4

Firmware update

Install ApexTX firmware on your Noble NB4. The updater verifies the transfer and installation before restarting the radio.

01 · UPDATE MODEOn the radio, select Settings → System → Update.
02 · USB CONNECTIONConnect the radio to this computer.
03 · FIRMWARE IMAGESelect a compatible firmware.bin file.
Select a firmware image to continue.0%

The radio must display ApexTX Update. A compatible bootloader is required. Keep the radio powered and the USB cable connected during installation.

ApexTX Updater runs locally on this computer. Firmware files are transferred directly to the radio.
