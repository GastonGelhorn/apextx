# Support

Use GitHub Issues for reproducible defects and focused feature requests. Search
existing issues first, then include the ApexTX version, source commit,
radio model, receiver model when relevant, steps, expected result, observed
result, and whether the problem also occurs without USB connected.

Before reporting an installation problem, read `docs/nb4/FLASH.md` and include
the final terminal output with credentials and device identifiers removed. Do
not upload transmitter backups, OTP, calibration records, factory firmware, or
USB serial numbers.

Safety or security problems should be reported privately as described in
`SECURITY.md`.
