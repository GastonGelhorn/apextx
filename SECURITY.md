# Security policy

## Supported versions

Security fixes are developed for the latest commit on `main` and the newest
published ApexTX release. Development builds and older alpha releases may
require an upgrade rather than a separate patch.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/GastonGelhorn/apextx/security/advisories/new)
for a vulnerability that could affect radio control, failsafe, firmware or
storage integrity, or host security. Do not open a public issue until a fix or
safe disclosure plan is available.

Include the ApexTX version, source commit, exact reproduction steps, and
the observed result. Remove transmitter serial numbers, OTP contents, factory
calibration, private firmware dumps, credentials, and personal data before
submitting evidence.

Ordinary setup questions and non-security defects belong in GitHub Issues.
